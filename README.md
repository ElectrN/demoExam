# 🎓 Портал «Корочки.есть»

Информационная система для записи на курсы дополнительного профессионального образования.  
Разработан в рамках демонстрационного экзамена по специальности **09.02.07 «Информационные системы и программирование»**, квалификация - разработчик веб- и мультимедийных приложений.

---

## 📂 Структура проекта

```text
korochki-portal/
├── public/                 # HTML-страницы (фронтенд)
│   ├── index.html          # Главная страница со слайдером
│   ├── login.html          # Авторизация
│   ├── register.html       # Регистрация
│   ├── dashboard.html      # Личный кабинет пользователя
│   └── admin.html          # Панель администратора
├── api/                    # PHP-скрипты (бэкенд API)
│   ├── register.php        # Регистрация
│   ├── login.php           # Авторизация
│   ├── check-auth.php      # Проверка сессии
│   ├── logout.php          # Выход из системы
│   ├── applications.php    # Заявки пользователя + отзывы
│   └── admin.php           # Управление заявками (админ)
├── config/                 # Конфигурация
│   ├── db.php              # Подключение к MySQL через PDO
│   └── demoTrainin.sql     # Дамп структуры и ограничений БД
└── assets/                 # Статические ресурсы
    ├── css/style.css       # Стили и адаптивность
    ├── js/app.js           # Единый JS-скрипт для всех страниц 
    └── images/             # Изображения для слайдера и интерфейса
```
---
Стек:PHP 8.2 + PDO, MySQL, HTML5, CSS3, Bootstrap 5, JavaScript (ES6+)

## ⚙️ Функционал

| Модуль | Описание |
|--------|----------|
| 🔐 **Регистрация** | Валидация полей (логин, пароль, ФИО, телефон, email), хеширование паролей, проверка уникальности |
| 🔑 **Авторизация** | Проверка логина/пароля, разделение ролей (`user` / `admin`), безопасные сессии |
| 📝 **Личный кабинет** | Подача заявок, просмотр истории, оставление отзыва после статуса «Обучение завершено» |
| 🛡 **Админ-панель** | Просмотр всех заявок, смена статусов (`Идет обучение` / `Обучение завершено`), защита по роли |
| 📱 **Адаптивность** | Корректное отображение на смартфонах (390×844 px), мобильная вёрстка через Bootstrap + CSS-медиазапросы |
| 🖼 **Слайдер** | Автоматическая смена изображений каждые 3 сек, кнопки навигации, одинаковый размер слайдов |

## 🚀 Инструкция по запуску

1. Запустите модули **Apache** и **MySQL** в XAMPP Control Panel\Laragon.
2. Откройте `http://localhost/phpmyadmin` → создайте базу данных `demoTrainin`.
3. Перейдите во вкладку **SQL** → импортируйте файл `config/demoTrainin.sql`.
4. Скопируйте папку `demoExam` в директорию сервера:  
   `C:\xampp\htdocs\` (XAMPP) или `C:\laragon\www\` (laragon).
5. Откройте в браузере:  
   🔗 `http://localhost/demoExam/public/index.html`

> 🔑 **Тестовые данные для входа:**
> - Администратор: `login: Admin` / `password: KorokNET`
> - Обычный пользователь: создаётся через форму регистрации.
